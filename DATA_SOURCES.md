## Safe-source policy

Do not scrape Google Maps/Search results, delivery platforms, login-protected pages, or sources that disallow the intended use. Do not bypass anti-bot controls, rate limits, or access controls. Never use an LLM inference as factual menu evidence. A place listing is not proof that a restaurant serves a particular dish.

Before connecting an official-source fetcher, document its legal basis and provider terms, use an explicit allowlist/approval step, enforce DNS/IP and redirect SSRF controls, respect robots/terms and rate limits, bound response bytes/time/content type, and define retention/freshness rules. The current parser is offline and provides none of those fetch permissions. Never treat a pending source as authorized, a name-only identity match as resolved, a menu listing as current availability, or parsed content as verified merely because parsing succeeded.

The OSM adapter performs one user-triggered geocode for a manual area, followed by a bounded Overpass query; nearby search sends coordinates to Overpass only after an explicit action. It does not run autocomplete, bulk geocoding, scheduled refreshes, or systematic area downloads. Its public-endpoint use is an opt-in local prototype and must be re-evaluated against current OSM policies before multi-user or production use.
